
# CLN Army Evolution 3D

Jogo mobile 3D de evolução de exército.

## Como jogar
- Arraste para os lados para controlar o exército azul.
- Atravesse os portões para multiplicar seus soldados.
- Enfrente o exército vermelho no final da pista.
- Vença para avançar de fase.

## Tecnologia
- Godot 4.7.2
- Renderização Compatibility
- MultiMesh para otimizar a quantidade de soldados.
- Exportação Android por GitHub Actions.

## APK
O APK é gerado automaticamente pelo GitHub Actions e fica disponível nos artefatos da execução.
